The dashboard has no password yet, so it refuses to open. There is deliberately no default: a dashboard that ships with a known password is a dashboard anybody can read.

Set ADMIN_PASSWORD and restart:

docker compose:
  environment:
    ADMIN_PASSWORD: "a long random string"

or, running it directly:
  ADMIN_PASSWORD='a long random string' npm start

Changing the password signs out every open session, by design. Back to the site
