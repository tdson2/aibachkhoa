インターネットが止まっても、会話は止まらない。

OriMessenger は、相手が近くにいれば Bluetooth や同じ Wi-Fi でメッセージを送り、近くにいないときだけインターネットに切り替えます。すべてのメッセージはエンドツーエンドで暗号化されます。

OriMessenger を選ぶ理由

相手に届く 3 つの経路を、この順番で。

ほとんどのメッセンジャーは、インターネットが常にあることを前提にしています。OriMessenger は違います。話している相手がすぐそばにいれば、アプリが自動で最短の経路を選びます。

1. Bluetooth — 数メートル以内にいるとき

アプリは Bluetooth で近くにいる Ori ユーザーを見つけます。おおよそ 10〜30 メートル以内なら、メッセージはルーターも携帯基地局も通らず、端末から端末へ直接届きます。インターネットはまったく不要です。

2. Wi-Fi / LAN — 同じネットワーク

同じ Wi-Fi や有線ネットワーク上では、端末どうしが自動的に互いを見つけ、メッセージはローカルネットワークの中だけでやり取りされます。インターネットが遮断されたホテルやゲスト用 Wi-Fi でも使え、写真を送れるほど高速です。

3. インターネット — どちらも使えないとき

Bluetooth とローカルネットワークの両方が使えないときにだけ、メッセージは私たちのサーバーを経由します。名前、プロフィール、メッセージ、添付ファイルはすべてエンドツーエンドで暗号化されているため、サーバーはどれも読むことができません。ただし、誰が誰にいつ送ったかは見えます — メッセージを届けるためにそれが必要だからです — そして、それを最長 30 日間保持します。

しくみ

あなたのプライバシーを、わかりやすく。

スマートフォンに残るもの、保護されるもの、そして私たちに見えるもの・見えないもの。詳しくはプライバシーポリシーをご覧ください。

01

あなたの ID は端末の中に

あなたの ID は、初めてアプリを開いたときに端末上で作成されます。その秘密の部分がその端末から外に出ることはありません。

02

メッセージは封印されている

メッセージ、名前、アバター、添付ファイルはエンドツーエンドで暗号化されるため、読めるのは話している相手だけです。メッセージがインターネットを経由するとき、サーバーに見えるのは配信に必要な情報だけ — 誰から、誰宛てに、いつ送られたか — です。

03

友だち申請にプロフィールは含まれない

友だち申請に含まれるのはあなたの ID だけです。表示名とステータスは、相手が承認したあとにだけ、暗号化されてその人と共有されます。

04

履歴は端末の中に

チャット履歴はあなたの端末にのみ保存されます。アプリをアンインストールするか、アプリのデータを削除すると消去されます。私たちが管理するクラウドバックアップはありません。

インターネットが不安定な場所のために。

コンサート会場、地下鉄のトンネル、キャンプ場、ログイン画面が出るホテルの Wi-Fi、メッセンジャーアプリがブロックされる国。OriMessenger は、ひとつのネットワークが動いていることに頼らないので、使い続けられます。

  • 電話番号は不要

    登録は、端末上で生成される 16 文字の ID だけ。電話番号が漏れる SMS ゲートウェイもありません。

  • アカウントは不要

    メールアドレスもパスワードも、復旧手続きもありません。端末を失えば ID も失われます。これは意図した設計です。

  • 無料で、広告なし

    アプリは無料です。サブスクリプションもアプリ内課金も広告もありません。

  • 知らない人からは届かない

    メッセージを送れるのは、すでにあなたの ID を知っている人だけです。「近くの人」リストへの表示は、同じ画面でオプトインした場合のみです。
