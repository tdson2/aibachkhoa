プライバシーポリシー

OriMessenger — Windows、macOS、Linux、Android、iOS 向け。

最終更新日：2026 年 9 月 26 日

要約。OriMessenger にはアカウントも電話番号もありません。メッセージ本文、アバター、添付ファイルはすべて、2 台の端末の間でエンドツーエンドで暗号化されます。アプリがインターネットに接続する必要がある場合、私たちのリレーサーバーは開くことのできない暗号化メッセージを中継します — ただし、メッセージをルーティングする必要があるため、誰が誰に、いつ送ったかは見えます。2 つの事柄は意図的に秘密にしていません：あなたが選んだ表示名とステータステキストは、OriMessenger を実行している近くの端末なら誰でも読むことができ、またリレーは配信メタデータを最長 30 日間保持します。どちらも以下で説明します。

OriMessenger は、ベトナム・ハノイを拠点とする AIBachKhoa（Son Tran）が提供しています。連絡先はこのページの末尾にあります。

端末に保存されるもの

初回起動時に、アプリは端末上であなたの ID を作成します。これは、メッセージを保護し、メッセージが本当にあなたから送られたものであることを連絡先に証明するための暗号鍵一式と、16 文字のユーザー ID から成ります。秘密の部分があなたの端末から外に出ることはありません。以下のものはすべて、アプリ専用のプライベートなデータフォルダに保存されます：

プラットフォーム保存場所
WindowsWindows ユーザープロファイル内のアプリのデータフォルダ。
macOSmacOS ユーザーアカウント内のアプリのデータフォルダ。
Linuxホームディレクトリ内のアプリのデータフォルダ。
Androidアプリのプライベートストレージ。Android のクラウドバックアップの対象外なので、Google ドライブにはコピーされません。
iOSアプリのプライベートストレージ — チャット履歴と鍵が「ファイル」アプリや iTunes のファイル共有を通じて公開されることはありません。
  • あなたの ID 鍵。秘密の部分が端末から外に出ることはありません。
  • あなたが選んだ表示名、ステータステキスト、アバターの色、背景。
  • 友だちリスト、ブロックリスト、保留中の友だち申請。
  • チャット履歴と、送受信した添付ファイル。
  • 各会話の暗号鍵。
  • アプリの設定：言語、ライト／ダークモード、既定の送信チャネル。

アプリをアンインストールするか、アプリのデータを消去すると、上記はすべて削除されます。私たちが管理するクラウドバックアップはありません。

保存データの保護について、はっきりお伝えします。チャット履歴と秘密鍵は、アプリのデータフォルダに暗号化されずに保存されています。アプリはその上にパスフレーズや追加の暗号化を施していません。これらを保護しているのはオペレーティングシステムです：Android と iOS ではアプリのサンドボックス、デスクトップではユーザーアカウントとフルディスク暗号化（FileVault、BitLocker、LUKS）です。ロック解除された端末上で、あなたのユーザーとしてファイルを読める人なら誰でも、あなたのチャット履歴を読むことができます。これが気になる場合は、フルディスク暗号化と端末のパスコードを使用してください。

メッセージが通る 3 つのネットワーク経路

OriMessenger は次の順番で経路を試し、最初にうまくいった経路で止まります：

経路何が、どこへ送られるか
Bluetooth 端末は Bluetooth で自らを検出可能にし、近くにある他の OriMessenger 端末を探します。メッセージは端末から端末へ直接届きます — 携帯基地局もルーターも通らず、何もあなたのすぐ周囲の外には出ません。なお、他の人があなたを見つけられるよう、端末は小さな公開プロフィールも発信しています：近くの端末から見えるものを参照してください。
Wi-Fi / LAN 同じローカルネットワーク上の端末は互いに存在を通知し合い、その後直接接続します。通信はローカルネットワークの中だけで行われ、インターネットが遮断されていても機能します。この通知はネットワーク上のすべての端末から見えます：近くの端末から見えるものを参照してください。
インターネットリレー 上の 2 つが失敗したときのみ使われます。端末は AIBachKhoa が運営するリレーサーバーへの暗号化された接続を開き、受信者の ID 宛ての暗号化メッセージを引き渡します。リレーが何を保持するかはリレーサーバーから見えるもので正確に説明しています。

近くの端末から見えるもの

これは OriMessenger の中で唯一、エンドツーエンドで暗号化されていない部分です。表示名を決める前に理解しておく価値があります。

アカウントやサーバーなしで互いを見つけられるよう、各端末は小さな公開プロフィールを発信します。そこに含まれるのは、あなたのユーザー ID、表示名、ステータステキスト、アバターの色、そして公開鍵です。秘密鍵、チャット履歴、友だちリストが含まれることはありません。

このプロフィールは、範囲内でそれを探している人なら誰でも読むことができます — 連絡先だけではありません：

  • Bluetooth では、範囲内のどの端末でも読めるようにプロフィールが発信されます。ペアリングの手順も承認の確認もありません。そもそも知らない人があなたに友だち申請を送るには、あなたの名前を読める必要があるからです。
  • Wi-Fi では、同じプロフィールが、ローカルネットワーク上のすべての端末に送られる通知に含まれます。

プロフィールはあなたの ID で署名されているため、ネットワーク上の誰もあなたの名前を自分のアドレスに結びつけて発信することはできません。しかし、秘密ではありません。実際には：

  • 同じカフェ、オフィス、教室で OriMessenger を実行している人は誰でも、あなたが選んだ表示名とステータステキストを見ることができ、あなたの端末がその場にあることもわかります。
  • 表示されたくない場合は、「設定」で近くの人をオフにしてください。Bluetooth と Wi-Fi の両方で検出されなくなります。インターネットリレーは引き続き動作するので、既存の会話のメッセージはそのまま届きます。
  • 人の多い場所に行くことが予想される場合は、本名ではなくニックネームを使ってください。ユーザー ID 自体からは何もわかりませんが、入力した名前は入力したとおりに表示されます。

メッセージの内容がこれに含まれることは決してありません。2 台の端末がやり取りを始めると、プロフィールの交換以降はすべてエンドツーエンドで暗号化されます。

リレーサーバーから見えるもの

インターネットリレーは、メッセージを配信できるようになるまで保持します。各端末は暗号化された接続でリレーに接続し、自分がその ID の所有者であることを証明します。あなたの端末に、ID がわかっている相手宛てのメッセージがあると、リレーは次の内容を含むレコードを保存します：

  • 受信者のユーザー ID（16 文字）。
  • 送信者のユーザー ID — つまり、あなたの ID。リレーはブロックリストを適用し、受信者の端末が署名を検証できるようにするためにこれを必要とします。
  • タイムスタンプ。レコードの有効期限を判断するために使います。
  • 暗号化されたメッセージ。開けるのはあなたの端末と受信者の端末だけです。添付ファイルのデータや、名前、アバター、ステータスといった人が読めるメタデータもここに含まれます。
  • インターネット接続なら必ず伴うネットワーク情報：あなたの IP アドレスと一時的な接続 ID。

つまり、リレーは配信メタデータを知ることになります：誰が誰にメッセージを送ったか、いつ送ったか、そしておおよそのサイズです。オフラインの端末にも配信するという仕組みを保ったまま、これをなくす設計はできません。このメタデータが気になる場合は、サーバーがまったく関与しない Bluetooth や Wi-Fi で OriMessenger を使ってください。

リレーはブロックリストも保持します。あなたが誰かをブロックすると、その組（あなたの ID、相手の ID）がサーバー側に保存され、相手のメッセージがあなたの端末に届く前にリレーが拒否できるようになります。このリストに有効期限はありません。相手のブロックを解除したとき、またはご依頼があったときに削除されます。

リレーに見えないもの：

  • メッセージの本文やメディアの内容。リレーはそれを復号する鍵を持っていません。
  • あなたの表示名、アバター、ステータス — これらは暗号化されたメッセージの中に入って送られます。
  • 友だちリスト、保留中の申請、Bluetooth や Wi-Fi でやり取りしたもの。これらの経路はサーバーを一切通りません。
  • 電話番号、メールアドレス、第三者のアカウント。あなたの ID に紐づくものは一切ありません。

保存されたメッセージは、受信者の端末が受信を確認した時点、または 30 日後のいずれか早いほうで削除されます。

収集する情報（カテゴリ別）

Google Play のデータセーフティの形式に対応させています：

カテゴリ収集の有無詳細
個人情報（名前、メールアドレス、電話番号）当社は収集しないアカウントは作成されず、私たちがあなたの名前を受け取ることもありません。ただし、非公開でもない点にご注意ください：あなたが選んだ表示名とステータステキストは、検出の際に近くの端末へ発信されます — 近くの端末から見えるものを参照してください。メールアドレスと電話番号は一切収集しません。
連絡先（アドレス帳）いいえアプリは端末の連絡先を読み取りません。
位置情報（GPS または詳細な位置情報）いいえ要求せず、収集もしません。
メッセージ転送中のみ、暗号化された状態でリレーが扱うのは暗号化されたメッセージだけで、その内容を読むことはできません。ただし、配信メタデータ（送信者 ID、受信者 ID、タイムスタンプ）は配信まで、または 30 日間保持します — リレーサーバーから見えるものを参照してください。
写真とメディア添付したものだけ送るファイルはあなたが選びます。暗号化されたデータは選ばれたネットワーク経路を通って送られます。自動でアップロードされるものはありません。
アプリのアクティビティ、アプリ内の操作分析なしアプリには第三者の分析ツールは含まれていません。
アプリの情報とパフォーマンス（クラッシュログ）ご依頼時のみクラッシュレポートは端末内に記録されます。私たちに送る場合は、ご自身でファイルを添付していただきます。
デバイスなどの識別子いいえIMEI、Android ID、広告 ID はいずれも収集しません。

アプリが求める権限とその理由

権限必要な理由
付近のデバイス / Bluetooth（Android）近くの OriMessenger ユーザーを見つけ、インターネットを使わずに直接メッセージをやり取りするため。
位置情報（Android 11 以前）古いバージョンの Android では、Bluetooth スキャンと合わせてこの権限の付与が必要です。アプリは GPS を読み取らず、位置情報も使用しません。
インターネットアクセス（Android、Linux、Windows）Bluetooth と LAN が使えないときにリレーに接続するため。
ネットワークと Wi-Fi の状態（Android）Wi-Fi がオンかどうか、試す価値のある LAN に端末がつながっているかどうかを検出するため。
バックグラウンドでの実行と起動時の自動開始（Android）アプリがバックグラウンドにある間も近くのユーザーを探し、メッセージを配信し続けるため、そして再起動後に再開するため。任意 — 「設定」でオフにできます。
通知（Android 13 以降）メッセージ受信の通知を表示するため。
写真 / ファイルへのアクセス（Android、Windows、Linux）添付する写真や背景画像を選べるようにするため。読み取るのはあなたが選んだファイルだけです。
Bluetooth（macOS、iOS）Android と同じ目的：近くのユーザーを見つけ、インターネットを使わずにメッセージをやり取りするため。macOS と iOS ではシステムのダイアログで一度だけ確認され、あとから 設定 → プライバシーとセキュリティ → Bluetooth で取り消せます。
ローカルネットワーク（macOS、iOS）同じ Wi-Fi 上の端末を見つけて直接接続するため。拒否しても Bluetooth とインターネットリレーは動作します。
通知（macOS、iOS）メッセージ受信の通知を表示するため。任意。拒否しても失われるのはバナー表示だけです。
バックグラウンドでの Bluetooth（iOS）アプリがフォアグラウンドにないときも、近くの端末からメッセージを受信し続けるため。iOS はこれを強く制限しており、Android で可能な継続的なバックグラウンド動作を許可していません。アプリが完全に閉じている間、iOS はメッセージを一切配信できません。

第三者との共有

私たちはユーザーデータを販売せず、広告ネットワークと共有することもありません。あなたに関連する情報が私たちのシステムの外に出るのは、次の場合に限られます：

  • リレーをホストするインフラ事業者（ベトナムのクラウド事業者） — 彼らに見えるのはリレーを通過する暗号化メッセージであり、リレー自体に見えるもの以上ではありません。
  • 法執行機関。有効な要請に応じることが法的に義務づけられている場合。リレーが保持するのは暗号化メッセージと配信メタデータだけなので、有用な情報はわずかです。求められればその旨をお伝えします。
  • 合併または買収の際の承継事業者。いかなる移転においても、本ポリシーが引き継がれます。

保存期間と削除

チャット履歴、鍵の情報、プロフィール設定は、あなたが削除するまで端末に残ります。アプリをアンインストールすると、どのプラットフォームでも削除されます。

リレー上の未配信メッセージは、受信者が取得した時点、または 30 日後に破棄されます。配信済みのメッセージはただちに破棄されます。

サーバー側のブロック情報（あなたの ID とブロックした相手の ID の組）に有効期限はありません。アプリで相手のブロックを解除したとき、または ID を指定してリレーデータの消去をご依頼いただいたときに削除されます。

リレー通信のサーバーログ（接続メタデータ、タイムスタンプ、バイト数 — メッセージの中身もユーザー ID も含まない）は、運用上のデバッグのために最長 14 日間保持され、その後ローテーションで削除されます。

子どものプライバシー

OriMessenger は 13 歳未満のユーザーを対象としていません。保護者の同意が必要な法域では、その地域の規則に従います。子どもが ID を作成したと思われ、その削除を希望される場合は、その ID を添えて下記の連絡先までご連絡ください。リレー上の該当データを削除できます。

あなたの権利

アカウントが存在しないため、通常なら企業に対して行使する権利のほとんどは、あなた自身が端末上で直接行使できます：アクセス、訂正、削除、エクスポートはすべてアプリを開くことで行えます。アプリ内では、履歴全体の消去、連絡先の削除、近くの人をオフにして検出されないようにすること、そして不快なものを送ってくる相手のブロックや報告ができます。報告はあなたの端末上で作成され、下記の連絡先に送られます — 私たちは報告に対応し、ID を指定してリレーデータを削除することもできます。

私たちがお手伝いできること — リレー上のデータの削除、サーバー側のブロック情報の消去 — が必要な場合は、該当する ID を添えて下記の連絡先までご連絡ください。

セキュリティ

リレーへのインターネット通信はすべて転送中に暗号化されます。そのうえで、すべてのメッセージは 2 台の端末の間でエンドツーエンドで暗号化され、署名されるため、受信者は内容が改ざんされていないこと、そして本当にあなたから送られたものであることの両方を検証できます。リレーは、それを開ける鍵を一切持たずに結果を中継します。

端末上のデータは、アプリによって個別に暗号化されていません。端末に保存されるもので説明したとおり、チャット履歴と秘密鍵は、アプリのパスフレーズではなくオペレーティングシステムによって保護されています。アプリが提供していない保護があるかのように見せるより、はっきりお伝えしたいと考えています。

Android の APK と Google Play 版は、次のフィンガープリントを持つ証明書で署名されています：

SHA-256   8A:0D:79:F8:73:F4:8F:A6:F3:E5:BD:5A:C5:04:28:A5:21:C1:86:C4:B1:0A:46:20:EE:D3:89:BA:48:F4:33:32

Windows インストーラーはまだコード署名されていません。代わりに、ダウンロードページに掲載している SHA-256 と照合してください。

完全に安全なシステムは存在せず、私たちもそれ以上の約束はしません。脆弱性を見つけた場合は、公開せずに、詳細を contact@aibachkhoa.com までメールでお知らせください。
