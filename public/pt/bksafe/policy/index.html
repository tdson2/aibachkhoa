Resumo

O BKSafe é um conjunto de ferramentas de proteção e manutenção publicado pela AIBachKhoa (Son Tran), Vietnã. Há quatro versões: Windows, macOS, Linux e Android.

As versões para desktop não têm conta nem telemetria, e não enviam resultados para lugar nenhum. Cada verificação, cada dado e cada registro fica naquela máquina. A versão para Android coleta alguns dados operacionais, listados por completo abaixo.

As versões para desktop (Windows, macOS, Linux)

Essas três leem muita coisa sobre a sua máquina — esse é o trabalho delas. Mas nada disso sai da máquina. Especificamente, o app lê:

  • Dados de hardware: CPU, memória, temperatura, saúde do disco, tráfego de rede
  • O conteúdo dos arquivos nas pastas que você escolhe verificar, para procurar malware
  • A lista de processos, serviços, drivers e itens de inicialização
  • A configuração de segurança do sistema operacional: firewall, antimalware, criptografia de disco
  • Nomes e tamanhos de pastas, quando você usa o recurso de medição de armazenamento

Não há conta para entrar, nenhum identificador de dispositivo é gerado e não há análises nem relatórios de falhas embutidos. O conteúdo dos arquivos é verificado na máquina e depois descartado — não é copiado, não é enviado e não é guardado.

O que o app grava no disco fica na pasta de configuração da sua própria conta: a escolha de idioma, o modo claro/escuro, os limites de alerta e o registro das verificações que você executou. Desinstalar o app e apagar as configurações remove tudo isso.

Quando as versões para desktop se conectam

Exatamente duas conexões, e nenhuma delas leva seus dados:

Conexão Quando e por quê
Atualização das definições de malware É executada automaticamente ao abrir o app, para manter atualizadas as definições de malware do verificador. Somente download; nada é enviado além de uma requisição comum de arquivo.
Windows Update Somente quando você clica em "Verificar agora" na aba Atualizações. O app pergunta ao próprio serviço Windows Update do sistema operacional se há alguma atualização pendente; essa conexão acontece entre a sua máquina e a Microsoft.

Além dessas duas, as versões para desktop não abrem nenhuma outra conexão de rede. Você pode confirmar isso com qualquer ferramenta de monitoramento de rede — inclusive a própria tela Rede deste app.

O que a versão para Android coleta

A versão para Android coleta alguns dados para operar o serviço e detectar ameaças:

  • Endereço de e-mail e dados de uso
  • Informações do dispositivo: modelo, versão do sistema, identificadores de hardware, IMEI, Android ID
  • Com que frequência e por quanto tempo o app é usado, e quais ações são realizadas
  • Registros de falhas e métricas de desempenho
  • Nomes de pacote dos apps verificados, para detecção de ameaças

Não coletamos seus arquivos pessoais — fotos, vídeos, contatos, mensagens — a menos que você conceda acesso explicitamente para um recurso específico.

As permissões que a versão para Android pede, e por quê

Permissão Para que serve
MANAGE_EXTERNAL_STORAGE Para verificar as pastas de armazenamento em busca de malware.
PACKAGE_USAGE_STATS Para perceber apps com comportamento incomum em segundo plano.
READ_CALL_LOG Para comparar os números recebidos com uma lista de números fraudulentos.
VPNService Para monitorar o tráfego de rede no próprio dispositivo. É uma conexão local, dentro do aparelho — nenhum tráfego passa pelos nossos servidores.

Para que os dados são usados

Os dados coletados pela versão para Android são tratados somente para as seguintes finalidades:

  • Detectar ameaças de segurança
  • Melhorar e manter o funcionamento do app
  • Gerenciar sua conta
  • Cumprir obrigações legais
  • Entrar em contato com você quando necessário

Compartilhamento de dados

Temos o compromisso de não vender e não compartilhar dados de usuários com terceiros. Há três exceções, e as declaramos aqui em vez de escondê-las:

  • Prestadores de serviço que contratamos para operar o serviço (por exemplo, análises), e apenas no mínimo que o trabalho deles exige
  • Autoridades, quando a lei exigir
  • Uma parte adquirente, em caso de futura fusão ou transferência do negócio

Nas versões para desktop, nenhuma dessas situações ocorre: nenhum dado seu sai da máquina, então não há nada para compartilhar.

Armazenamento e retenção

Todos os dados relacionados ao funcionamento do app são tratados e armazenados no seu próprio dispositivo.

Apague-os desinstalando o app ou usando a função de exclusão embutida nele. Nas versões para desktop, apagar a pasta de configuração do app remove tudo o que ele já gravou.

Privacidade de crianças

O serviço não se destina a usuários menores de 13 anos. Quando a lei exigir o consentimento dos pais ou responsáveis, cumprimos essa exigência. Se você acredita que seu filho nos forneceu informações, entre em contato pelo endereço no rodapé desta página e nós as apagaremos.

Seus direitos

Você tem o direito de acessar, corrigir e apagar seus dados, e de se opor ao tratamento que fazemos deles. Envie as solicitações para o e-mail no rodapé desta página.

Nas versões para desktop, você pode exercer a maior parte desses direitos sozinho, sem pedir a ninguém: os únicos dados que existem são algumas configurações e arquivos de log dentro da sua própria pasta.

Segurança

Como as versões para desktop mantêm tudo na própria máquina, seus dados ficam protegidos pelas defesas do próprio sistema operacional — sua conta de usuário e as permissões de arquivo dela. Para os dados que a versão para Android de fato nos envia, usamos conexões criptografadas em trânsito e mantemos o acesso no mínimo necessário. Nenhum sistema é perfeitamente seguro, e não afirmamos o contrário.

Alterações nesta política

Esta política pode ser atualizada conforme o app muda. A data de "última atualização" no topo sempre reflete a versão em vigor. Para mudanças que afetem de forma relevante o tratamento dos seus dados, avisaremos no app em vez de editar esta página discretamente.
