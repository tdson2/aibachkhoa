OriMessenger — Windows, macOS, Linux, Android, iOS용.

최종 업데이트: 2026년 9월 26일

요약. OriMessenger에는 계정도 전화번호도 없습니다. 모든 메시지 본문, 아바타, 첨부 파일은 두 기기 사이에서 종단 간 암호화됩니다. 앱이 인터넷을 사용해야 하는 경우, 저희 릴레이 서버는 자신이 열어 볼 수 없는 암호화된 메시지를 전달합니다 — 하지만 메시지를 라우팅해야 하므로 누가 누구에게 언제 보냈는지는 알 수 있습니다. 다음 두 가지는 의도적으로 비밀이 아닙니다: 사용자가 정한 표시 이름과 상태 메시지는 OriMessenger를 실행 중인 근처의 모든 기기가 읽을 수 있으며, 릴레이는 전달 메타데이터를 최대 30일 동안 보관합니다. 두 가지 모두 아래에서 설명합니다.

앱 배포자

OriMessenger는 베트남 하노이에 기반을 둔 AIBachKhoa(Son Tran)가 배포합니다. 연락처 정보는 이 페이지 하단에 있습니다.

기기에 저장되는 정보

앱을 처음 실행하면 기기에서 사용자의 신원 정보가 생성됩니다. 이는 메시지를 보호하고 연락처에게 메시지가 정말 본인에게서 왔음을 증명하는 데 쓰이는 암호화 키 세트와 16자리 사용자 ID로 이루어집니다. 비밀 부분은 절대 기기를 벗어나지 않습니다. 아래의 모든 정보는 앱 전용 비공개 데이터 폴더에 보관됩니다:

플랫폼보관 위치
WindowsWindows 사용자 프로필 안의 앱 데이터 폴더.
macOSmacOS 사용자 계정 안의 앱 데이터 폴더.
Linux홈 디렉터리 안의 앱 데이터 폴더.
Android앱 전용 비공개 저장소. Android 클라우드 백업에서 제외되므로 Google Drive에 복사되지 않습니다.
iOS앱 전용 비공개 저장소 — 채팅 기록과 키는 파일 앱이나 iTunes 파일 공유를 통해 절대 노출되지 않습니다.
  • 신원 키. 비밀 부분은 절대 기기를 벗어나지 않습니다.
  • 사용자가 정한 표시 이름, 상태 메시지, 아바타 색상 및 배경.
  • 친구 목록, 차단 목록, 대기 중인 친구 요청.
  • 채팅 기록과 주고받은 첨부 파일.
  • 각 대화의 암호화 키.
  • 앱 환경설정: 언어, 라이트/다크 모드, 기본 전송 채널.

앱을 삭제하거나 앱 데이터를 지우면 위의 모든 정보가 삭제됩니다. 저희가 관리하는 클라우드 백업은 없습니다.

저장 데이터 보호에 대해 분명히 알아 두세요. 채팅 기록과 개인 키는 앱 데이터 폴더에 암호화되지 않은 상태로 저장됩니다. 앱은 그 위에 암호 문구나 추가 암호화 계층을 더하지 않습니다. 이 데이터는 운영체제가 보호합니다. Android와 iOS에서는 앱 샌드박스가, 데스크톱에서는 사용자 계정과 전체 디스크 암호화(FileVault, BitLocker, LUKS)가 보호합니다. 잠금 해제된 기기에서 사용자 권한으로 파일을 읽을 수 있는 사람이라면 누구나 채팅 기록을 읽을 수 있습니다. 이 점이 중요하다면 전체 디스크 암호화와 기기 암호를 사용하세요.

메시지가 전달되는 세 가지 네트워크 경로

OriMessenger는 다음 순서로 경로를 시도하며, 처음으로 작동하는 경로에서 멈춥니다:

경로무엇이 어디로 전달되는가
Bluetooth 기기가 Bluetooth로 자신을 검색 가능하게 만들고 근처의 다른 OriMessenger 기기를 찾습니다. 메시지는 기기에서 기기로 직접 전달됩니다 — 기지국도, 공유기도 거치지 않으며 어떤 것도 바로 주변 범위를 벗어나지 않습니다. 단, 다른 사람이 찾을 수 있도록 기기가 작은 공개 프로필도 게시한다는 점에 유의하세요: 근처 기기가 볼 수 있는 정보를 참고하세요.
Wi-Fi / LAN 같은 로컬 네트워크에 있는 기기들은 서로에게 자신을 알린 뒤 직접 연결합니다. 트래픽은 로컬 네트워크 안에만 머물며 인터넷이 차단된 상황에서도 작동합니다. 이 알림은 네트워크상의 모든 기기에 보입니다: 근처 기기가 볼 수 있는 정보를 참고하세요.
인터넷 릴레이 위의 두 경로가 모두 실패한 경우에만 사용됩니다. 기기는 AIBachKhoa가 운영하는 릴레이 서버에 암호화된 연결을 열고, 수신자 ID를 수신 주소로 하는 암호화된 메시지를 넘겨줍니다. 릴레이가 정확히 무엇을 보관하는지는 릴레이 서버가 볼 수 있는 정보에 설명되어 있습니다.

근처 기기가 볼 수 있는 정보

이 부분은 OriMessenger에서 유일하게 종단 간 암호화되지 않는 부분이므로, 표시 이름을 정하기 전에 이해해 두는 것이 좋습니다.

계정이나 서버 없이도 서로를 찾을 수 있도록, 각 기기는 작은 공개 프로필을 게시합니다. 여기에는 사용자 ID, 표시 이름, 상태 메시지, 아바타 색상, 그리고 공개 키가 포함됩니다. 개인 키, 채팅 기록, 친구 목록은 절대 포함되지 않습니다.

이 프로필은 연락처뿐만 아니라 범위 안에서 이를 찾는 누구나 읽을 수 있습니다:

  • Bluetooth에서는 범위 안의 모든 기기가 읽을 수 있도록 프로필이 게시됩니다. 애초에 낯선 사람이 친구 요청을 보내려면 이름을 읽을 수 있어야 하므로, 페어링 단계나 승인 요청은 없습니다.
  • Wi-Fi에서는 동일한 프로필이 로컬 네트워크의 모든 기기에 보내는 알림에 포함됩니다.

프로필은 사용자의 신원으로 서명되므로, 네트워크상의 누구도 여러분의 이름을 자신의 주소에 붙여 광고할 수 없습니다. 하지만 비밀은 아닙니다. 실제로는 다음과 같습니다:

  • 같은 카페, 사무실, 교실에서 OriMessenger를 실행 중인 사람이라면 누구나 사용자가 정한 표시 이름과 상태 메시지를 볼 수 있고, 사용자의 기기가 그곳에 있다는 것을 알 수 있습니다.
  • 노출되고 싶지 않다면 설정에서 근처를 끄세요. 그러면 Bluetooth와 Wi-Fi 모두에서 검색되지 않습니다. 인터넷 릴레이는 계속 작동하므로 기존 대화의 메시지는 여전히 전달됩니다.
  • 공공장소에 있을 예정이라면 실명 대신 닉네임을 사용하세요. 사용자 ID 자체로는 아무것도 드러나지 않지만, 입력한 이름은 입력한 그대로 표시됩니다.

메시지 내용은 여기에 절대 포함되지 않습니다. 두 기기가 대화하기로 하면 프로필 교환 이후의 모든 것은 종단 간 암호화됩니다.

릴레이 서버가 볼 수 있는 정보

인터넷 릴레이는 메시지를 전달할 수 있을 때까지 보관합니다. 각 기기는 암호화된 연결로 릴레이에 접속하고 자신이 해당 ID의 소유자임을 증명합니다. 사용자의 기기가 ID를 알고 있는 상대에게 보낼 메시지가 있으면, 릴레이는 다음 정보가 담긴 기록을 저장합니다:

  • 수신자의 사용자 ID(16자리).
  • 발신자의 사용자 ID — 즉, 사용자 본인의 ID. 릴레이는 차단 목록을 적용하고 수신자의 기기가 서명을 검증할 수 있도록 하기 위해 이 정보가 필요합니다.
  • 기록 만료에 사용되는 타임스탬프.
  • 사용자의 기기와 수신자의 기기만 열 수 있는 암호화된 메시지. 여기에는 첨부 파일 데이터와 이름, 아바타, 상태 등 사람이 읽을 수 있는 메타데이터가 모두 포함됩니다.
  • 모든 인터넷 연결에 따라오는 네트워크 정보: IP 주소와 임시 연결 ID.

따라서 릴레이는 전달 메타데이터, 즉 누가 누구에게 언제 메시지를 보냈는지와 메시지의 대략적인 크기를 알게 됩니다. 오프라인 기기에 메시지를 전달하면서 이를 설계상 없앨 수는 없습니다. 이 메타데이터가 중요하다면 서버가 전혀 관여하지 않는 Bluetooth나 Wi-Fi로 OriMessenger를 사용하세요.

릴레이는 차단 목록도 보관합니다. 누군가를 차단하면 (사용자의 ID, 상대의 ID) 쌍이 서버에 저장되어, 릴레이가 상대의 메시지를 사용자의 기기에 도달하기 전에 거부할 수 있습니다. 이 목록에는 만료 기한이 없으며, 차단을 해제하거나 요청하는 경우에 삭제됩니다.

릴레이가 볼 수 없는 정보:

  • 메시지 텍스트나 미디어 내용. 이를 복호화할 키가 없습니다.
  • 표시 이름, 아바타, 상태 — 이 정보는 암호화된 메시지 안에 담겨 전달됩니다.
  • 친구 목록, 대기 중인 요청, 또는 Bluetooth나 Wi-Fi로 주고받은 모든 것. 이 경로들은 서버를 전혀 거치지 않습니다.
  • 전화번호, 이메일 주소, 제3자 계정. 사용자의 ID에 연결된 이런 정보는 없습니다.

저장된 메시지는 수신자의 기기가 수신을 확인하는 즉시 또는 30일이 지나면, 둘 중 먼저 도래하는 시점에 삭제됩니다.

알림(macOS, iOS)새 메시지 알림을 표시하기 위해. 선택 사항이며, 거부해도 배너 알림만 표시되지 않습니다.
백그라운드 Bluetooth(iOS)앱이 포그라운드에 있지 않은 동안에도 근처 기기로부터 메시지를 계속 받기 위해. iOS는 이를 크게 제한하며 Android에서 허용되는 지속적인 백그라운드 동작을 허용하지 않습니다. 앱이 완전히 종료된 동안에는 iOS에서 메시지를 전혀 전달할 수 없습니다.

제3자와의 공유

저희는 사용자 데이터를 판매하지 않으며, 광고 네트워크와 공유하지 않습니다. 사용자와 관련된 정보가 저희 시스템 밖으로 나가는 경우는 다음뿐입니다:

  • 릴레이를 호스팅하는 인프라 제공업체(베트남의 클라우드 제공업체) — 이들은 릴레이를 통과하는 암호화된 메시지를 볼 수 있지만, 릴레이 자체가 볼 수 있는 것 이상은 볼 수 없습니다.
  • 유효한 요청에 응할 법적 의무가 있는 경우의 법 집행 기관. 릴레이는 암호화된 메시지와 전달 메타데이터만 보관하므로 제공할 수 있는 유용한 정보는 적으며, 요청을 받으면 그 사실을 밝히겠습니다.
  • 합병 또는 인수 시의 승계 법인. 모든 이전에는 이 방침이 그대로 승계됩니다.

보관 및 삭제

채팅 기록, 키 자료, 프로필 설정은 사용자가 삭제할 때까지 기기에 남습니다. 모든 플랫폼에서 앱을 삭제하면 함께 삭제됩니다.

릴레이에 있는 미전달 메시지는 수신자가 가져가면, 또는 30일이 지나면 삭제됩니다. 전달된 메시지는 즉시 삭제됩니다.

서버 측 차단 항목(사용자의 ID와 차단한 상대의 ID 쌍)에는 만료 기한이 없습니다. 앱에서 차단을 해제하거나, ID를 알려 주며 릴레이 데이터 삭제를 요청하면 삭제됩니다.

릴레이 트래픽에 대한 서버 측 로그(연결 메타데이터, 타임스탬프, 바이트 수 — 메시지 페이로드와 사용자 ID는 포함되지 않음)는 운영상 디버깅을 위해 최대 14일 동안 보관된 뒤 순환 삭제됩니다.

아동의 개인정보 보호

OriMessenger는 13세 미만 사용자를 대상으로 하지 않습니다. 보호자 동의가 필요한 관할권에서는 현지 규정을 따릅니다. 아동이 ID를 만들었다고 생각되어 삭제를 원하시면 해당 ID와 함께 아래 주소로 연락해 주세요. 릴레이에 있는 해당 데이터를 삭제할 수 있습니다.

사용자의 권리

계정이 없기 때문에, 보통 회사를 상대로 행사하는 대부분의 권리는 기기에서 직접 행사할 수 있습니다. 열람, 정정, 삭제, 내보내기는 모두 앱을 여는 것으로 해결됩니다. 앱 안에서 전체 기록을 지우고, 연락처를 삭제하고, 근처를 꺼서 검색되지 않도록 하고, 불쾌한 내용을 보내는 사람을 차단하거나 신고할 수 있습니다. 신고는 기기에서 작성되어 아래 주소로 전송됩니다 — 저희는 신고에 따라 조치하며, ID 기준으로 릴레이 데이터를 삭제할 수 있습니다.

저희가 도와드릴 수 있는 일 — 릴레이에 있는 데이터 삭제, 서버 측 차단 항목 삭제 등 — 이 필요하시면 해당 ID와 함께 아래 주소로 연락해 주세요.

보안

릴레이로 가는 모든 인터넷 트래픽은 전송 중에 암호화됩니다. 그에 더해 모든 메시지는 두 기기 사이에서 종단 간 암호화되고 서명되므로, 수신자는 내용이 변조되지 않았는지와 메시지가 정말 발신자에게서 왔는지를 모두 확인할 수 있습니다. 릴레이는 이를 열 수 있는 키를 전혀 보유하지 않은 채 그 결과물만 전달합니다.

기기에 저장된 데이터는 앱이 별도로 암호화하지 않습니다. 기기에 저장되는 정보에서 설명한 것처럼, 채팅 기록과 개인 키는 앱 암호 문구가 아니라 운영체제에 의해 보호됩니다. 앱이 제공하지 않는 보호를 제공하는 것처럼 암시하기보다는 이를 분명히 밝혀 두고자 합니다.
