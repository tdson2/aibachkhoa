BKSafe

macOS · Windows · Android

내 기기를 한눈에.

BKSafe는 기기 상태를 지켜보고, 악성코드를 검사하고, 불필요한 파일을 정리하며, 네트워크 트래픽을 살핍니다. 모든 분석은 기기에서 이루어지며, 파일은 단 하나도 기기 밖으로 나가지 않습니다.

분석은 기기 안에서

모든 검사와 측정은 기기 자체에서 실행됩니다. 파일이 서버로 업로드되는 일은 없습니다.

Apple 공증 완료

Developer ID로 서명하고 공증을 받았습니다. 응용 프로그램 폴더로 끌어다 놓고 열기만 하면 됩니다. 경고도, 차단 해제도 없습니다.

설치 없이 실행

Windows 버전은 어디로든 복사할 수 있는 폴더입니다. USB 메모리, 네트워크 공유 폴더, 다른 PC에서도. 설치 프로그램 없이 더블클릭하면 실행됩니다.

프로세서, 그래픽, 메모리, 저장 공간, 드라이브 상태, 온도, 네트워크까지 Mac 모든 부분의 실시간 수치를 한곳에서 보여 주며, 정리, 악성코드 검사, 보안 점검도 함께 제공합니다.

시스템

CPU, GPU, 메모리, 저장 공간, 네트워크를 나란히. 기기 사양, 가동 시간, 프로세스 수, 메모리 압력을 한 화면에서.

코어별 CPU

코어마다의 부하, 시간에 따른 평균 부하, CPU를 가장 많이 쓰는 프로세스.

GPU

그래픽 칩이 얼마나 바쁜지, 그래픽 메모리를 얼마나 쓰고 있는지.

메모리

메모리가 어디에 쓰이는지, 시스템이 받는 압력은 어느 정도인지, 얼마나 스왑되었는지.

디스크 상태

드라이브 상태를 한눈에. 이상 징후와 드라이브 온도도 함께 보여 줍니다.

온도

기기 곳곳의 온도, 그리고 열 때문에 Mac이 느려지고 있는지.

네트워크

어떤 앱이 데이터를 주고받는지, 그 양은 얼마인지, 이 Mac이 어떤 포트를 열어 두었는지.

이상 알림

수치가 예상 범위를 계속 벗어나 있을 때 알려 줍니다. 임계값은 직접 정하므로 평범한 순간적 상승은 문제로 보고되지 않습니다.

클리너

캐시, 로그, 임시 파일, 삭제한 앱의 잔여물을 찾아냅니다. 목록을 확인한 뒤 무엇을 지울지 직접 결정합니다.

악성코드 검사

Mac과 함께 시작되는 모든 항목을 포함해 악성코드가 숨기 쉬운 곳을 검사합니다.

보안 점검

macOS의 기본 보호 기능, 열린 포트, 시작 항목을 확인합니다. 설정을 읽기만 하고, 아무것도 바꾸지 않습니다.

설정

알림 임계값을 정하고, 알림 표시 여부를 선택하며, 앱이 백그라운드에서 얼마나 작동할지 결정합니다.

앱이 전체 디스크 접근 권한을 요청하는 이유

BKSafe는 앱 자체의 컨테이너 밖에 있는 하드웨어, 저장 공간, 네트워크, 보안 설정을 보고하고, 시스템 곳곳에 남은 불필요한 파일을 정리합니다. 이를 위해서는 전체 디스크 접근 권한이 필요하며, 이것이 BKSafe를 Mac App Store가 아닌 Developer ID와 Apple 공증으로 배포하는 이유입니다. 이 권한은 읽기에만 사용되며, 아무것도 외부로 보내지 않습니다.

세 단계로 설치

  1. 1

    BKSafe-1.3.3.dmg를 다운로드합니다.

  2. 2

    파일을 열고 BKSafe를 응용 프로그램으로 끌어다 놓습니다.

  3. 3

    Launchpad나 응용 프로그램 폴더에서 BKSafe를 엽니다.

오른쪽 클릭 후 열기도, 설정에서 차단 해제도, "확인되지 않은 개발자" 경고도 없습니다. 네트워크에 연결되어 있지 않아도 Mac에서 문제없이 열립니다.

Windows 버전

PC 구석구석, 가려진 곳 없이.

Windows용으로 만든 같은 BKSafe: 불필요한 파일 정리, 저장 공간과 메모리 분석, 바이러스 검사, 랜섬웨어 방어, 백그라운드 서비스 점검, 네트워크 활동, 그리고 수치가 범위를 벗어날 때의 알림. 설치 프로그램 없이 압축을 풀고 바로 실행하세요.

  • 버전 1.3.0 · 빌드 23
  • Windows 10 64비트 이상
  • 포터블 — 설치 불필요

클리너

Windows와 앱이 남긴 것들, 즉 임시 파일, 업데이트 잔여 파일, 브라우저 캐시를 찾아냅니다. 목록만 보여 주며, 직접 고르기 전에는 아무것도 삭제하지 않습니다.

저장 공간

어떤 폴더와 파일이 공간을 차지하는지. 폴더별, 큰 파일 순, 파일 유형별로 볼 수 있습니다.

메모리

RAM이 어디에 쓰이는지, 어떤 앱이 붙잡고 있는지.

바이러스 검사

선택한 폴더에서 바이러스와 기타 악성코드를 검사합니다.

랜섬웨어 방어

문서를 지켜보다가 랜섬웨어가 암호화를 시작하면 즉시 알려 줍니다.

시스템 안전

Windows 기본 보호 기능이 켜져 있는지, 기기와 함께 무엇이 시작되는지, 대기 중인 업데이트가 있는지.

시스템 서비스

시스템 권한으로 백그라운드에서 실행되는 항목. 새로 설치된 서비스는 바로 표시됩니다.

네트워크

얼마나 주고받는지, 어떤 프로세스가 주고받는지, 외부로 열린 포트는 무엇인지.

드라이브

드라이브 상태와 읽기·쓰기 처리량.

모니터

기기 전체를 한 화면에서, 발생한 모든 알림의 기록과 함께. 알림은 수치가 설정한 범위를 벗어날 때만 나타납니다.

검사 기록

모든 검사가 기록됩니다: 언제 실행했는지, 무엇을 대상으로 했는지, 무엇을 찾았는지. 취소된 실행도 기록되어 기록이 빠짐없이 남습니다.

예약 검사

매일, 매주, 매월 알아서 실행되는 검사. 다음 예약 실행 시각이 항상 표시됩니다.

시스템과 함께 시작

BKSafe를 Windows와 함께 시작해 로그인하는 순간부터 백그라운드 보호가 작동하게 합니다.

위젯으로 축소

앱을 바탕 화면의 작은 패널로 축소해 핵심 실시간 수치를 표시하고, 확인이 필요한 일이 생기면 표시등으로 알려 줍니다.

관리자 권한이 필요한 경우

일상적인 사용에는 일반 사용자 권한으로 충분합니다. Windows 자체의 불필요한 파일 정리, 서비스 중지 또는 비활성화, 일부 네트워크 수치 같은 몇 가지 시스템 수준 작업에는 관리자 권한이 필요합니다. 이 경우 설정 또는 클리너 화면에서 관리자 권한으로 다시 시작을 누르세요.

세 단계로 실행

  1. 1

    BKSafe-1.3.0-win-x64-portable.zip을 다운로드하고 폴더에 압축을 풉니다.

  2. 2

    bksafe.exe를 더블클릭합니다. 설치 단계는 없습니다.

  3. 3

    시스템 수준 정리를 하려면 앱에서 관리자 권한으로 다시 시작을 누릅니다.

폴더 전체를 어디에 복사해도 실행됩니다. USB 메모리, 네트워크 공유 폴더, 다른 PC에서도. 폴더 안의 내용만 함께 두면 됩니다. 설정은 따로 보관되므로 앱 폴더를 지워도 사라지지 않습니다. 앱에 아직 코드 서명 인증서가 없어서 처음 실행할 때 파란색 SmartScreen 창이 뜰 수 있습니다. 추가 정보를 누른 다음 실행을 누르세요.

Linux 버전

Linux 기기를 빠짐없이 측정합니다.

Linux용으로 만든 같은 BKSafe: 불필요한 파일 정리, 저장 공간과 메모리 분석, 바이러스 검사, 실시간 보호, 서비스 점검, 드라이브 상태, 온도, 네트워크 활동. 표준 .deb로 설치되고 깔끔하게 제거됩니다.

  • 버전 1.3.1 · 빌드 24
  • Debian 12 / Ubuntu 22.04 이상
  • .deb — 깔끔한 설치와 제거

세 단계로 설치

  1. 1

    BKSafe-1.3.1-linux-amd64.deb를 다운로드합니다.

  2. 2

    더블클릭해 소프트웨어 설치 프로그램에서 열거나, 터미널에서 sudo apt install ./BKSafe-1.3.1-linux-amd64.deb를 실행합니다.

  3. 3

    애플리케이션 메뉴에서 BKSafe를 열거나, 터미널에 bksafe를 입력합니다.

BKSafe는 애플리케이션 메뉴에 항목을 추가하며, sudo apt remove bksafe로 깔끔하게 제거됩니다. 설정은 따로 보관되므로 패키지를 제거해도 사라지지 않습니다.

Android 버전

스스로를 지키는 휴대폰.

앱과 파일은 휴대폰 자체에서 검사하고, 사기 전화는 벨이 울리기 전에 차단하며, 개인 데이터는 PIN 뒤에 안전하게 둡니다. 이 모든 것에 서버가 필요하지 않습니다.

  • Google Play에서 제공
  • 무료 다운로드
  • 베트남어 인터페이스

  • 기기에서 빠른 검사

    한 번의 탭으로 휴대폰에 설치된 모든 앱과 파일을 검사합니다. 분석이 기기에서 실행되므로 연결이 전혀 없어도 작동합니다.

  • 사기 전화 차단

    스팸 번호와 사기 번호는 휴대폰이 울리기 전에 차단되며, 누가 차단되었는지 기록으로 확인할 수 있습니다.

  • 보안 보관함

    비밀번호와 민감한 메모를 암호화해 저장하고, 나만 아는 PIN으로 엽니다.

  • 백그라운드 서비스 점검

    사용하지 않는 동안 몰래 실행되거나, 배터리를 소모하거나, 데이터를 보내는 앱을 보여 줍니다.

  • 안전 점수

    휴대폰 상태를 하나의 숫자로. 점수를 올리려면 무엇을 고쳐야 하는지 목록도 함께 보여 줍니다.

  • 정리 및 개인정보 보호

    불필요한 파일을 정리하고, 인터넷 사용 기록을 지우며, 앱이 계속 보유한 권한을 점검합니다.

BKSafe Lite

com.tdson.bksafelite

오래되거나 느린 휴대폰이라면? Lite 버전을 쓰세요.

BKSafe Lite는 오래되었거나 성능이 낮은 휴대폰을 위해 만들었습니다. 백그라운드 서비스가 없고, 홈 화면에서 바로 쓸 수 있는 몇 가지 도구만 담았습니다.

  • 파일 검사휴대폰의 파일에서 위협을 검사합니다. 연결이 필요 없습니다.
  • 불필요한 파일 정리남은 파일을 찾아 목록과 확보할 수 있는 용량을 보여 준 뒤, 선택한 것을 삭제합니다.
  • 배터리 점검충전량, 온도, 충전 횟수, 그리고 배터리 상태가 어떻게 유지되고 있는지.
  • 네트워크 속도 측정다운로드, 업로드, 지연 시간, 지터와 함께 연결 유형과 패킷 손실까지.

백그라운드 서비스 점검, 트래픽 모니터링, 비밀번호 보관함, 안전 점수는 BKSafe 정식 버전에서 사용할 수 있습니다.

자주 묻는 질문.

BKSafe가 내 데이터를 어딘가로 보내나요?

아니요. 검사와 측정은 전적으로 기기에서 실행됩니다. 앱은 파일, 프로세스 목록, 기기 수치를 어떤 서버에도 업로드하지 않습니다. 프로세스별 트래픽을 보여 주는 앱의 네트워크 화면에서 직접 확인할 수도 있습니다.

macOS 버전은 왜 Mac App Store에 없나요?

Mac App Store의 앱은 샌드박스에서 실행되어야 하는데, 샌드박스는 BKSafe가 보고하는 하드웨어, 저장 공간, 시스템 정보에 대한 접근을 막습니다. 그래서 BKSafe는 Developer ID와 Apple 공증으로 배포됩니다.

열 때 macOS가 차단하지 않나요?

아니요. macOS 버전은 서명되어 있고 Apple의 공증을 받았습니다. 응용 프로그램 폴더로 끌어다 놓고 다른 앱처럼 열면 됩니다. 네트워크에 연결되어 있지 않아도 괜찮습니다.

Intel Mac에서도 작동하나요?

네. 하나의 다운로드로 Intel Mac과 Apple Silicon Mac 모두에서 네이티브로 실행됩니다. 버전을 고를 필요가 없습니다.

Windows 버전은 설치해야 하나요?

아니요. 포터블 패키지이므로 폴더에 압축을 풀고 bksafe.exe를 더블클릭하면 됩니다. 폴더 전체를 USB 메모리나 다른 PC에 복사해도 그대로 실행됩니다. 폴더 안의 내용만 함께 두면 됩니다. 설정은 앱 폴더와 따로 보관됩니다.

Windows에 "Windows의 PC 보호"가 표시됩니다. 어떻게 하나요?

추가 정보를 누른 다음 실행을 누르세요. 앱에 아직 코드 서명 인증서가 없어서 처음 몇 번 실행할 때 SmartScreen이 경고합니다. 아예 실행되지 않으면 bksafe.exe를 마우스 오른쪽 버튼으로 클릭 → 속성 → 일반 탭 아래쪽의 차단 해제에 체크 → 확인을 누르세요. 다운로드 섹션에 게시된 SHA-256과 비교해 파일이 손상되지 않았는지 확인할 수 있습니다.

언제 관리자 권한으로 실행해야 하나요?

몇 가지 시스템 수준 작업에만 필요합니다: Windows 자체의 불필요한 파일 정리, 서비스 중지 또는 비활성화, 일부 네트워크 수치. 이 경우 앱에서 관리자 권한으로 다시 시작을 누르세요. 일상적인 사용에는 일반 사용자 권한으로 충분합니다.

다운로드한 파일이 진짜인지 어떻게 알 수 있나요?

Mac에서는 shasum -a 256 BKSafe-1.3.3.dmg를 실행하고, Windows에서는 PowerShell을 열어 Get-FileHash BKSafe-1.3.0-win-x64-portable.zip -Algorithm SHA256을 실행하고, Linux에서는 sha256sum BKSafe-1.3.1-linux-amd64.deb를 실행하세요. 결과를 다운로드 섹션에 게시된 SHA-256과 비교해 문자열이 일치하면 파일이 손상되지 않은 것입니다.

각 버전이 계정을 공유하나요?

아니요. macOS, Windows, Android 앱은 서로 독립적이며 각자의 기기에서 작동합니다. 공유 계정이 없고, 앱 사이에 동기화되는 것도 없습니다.

Lite는 정식 BKSafe와 무엇이 다른가요?

BKSafe Lite(com.tdson.bksafelite)는 파일 검사, 불필요한 파일 정리, 배터리 점검, 네트워크 속도 측정을 제공합니다. 백그라운드 서비스를 실행하지 않아 오래된 휴대폰에서도 가볍습니다. 사기 전화 차단, 백그라운드 서비스 점검, 보관함, 안전 점수는 BKSafe 정식 버전에 있습니다. 서로 다른 앱이므로 둘 다 설치해 둘 수 있습니다.
