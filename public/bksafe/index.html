Why the app asks for Full Disk Access

BKSafe reports on hardware, storage, network and security settings that sit outside an app's own container, and clears junk files left across the system. That needs Full Disk Access, and it is why BKSafe is distributed with a Developer ID and Apple notarization rather than through the Mac App Store. The access is used for reading only, and nothing is sent anywhere.

Installed in three steps

  1. 1

    Download BKSafe-1.3.2.dmg.

  2. 2

    Open it and drag BKSafe into Applications.

  3. 3

    Open BKSafe from Launchpad or the Applications folder.

No right-click-then-Open, no trip to Settings to unblock it, no “unidentified developer” warning. Apple's notarization ticket is stapled to both the DMG and the app inside it, so the Mac opens it fine even with no network connection.

When you need administrator rights

For everyday use the normal build is enough — auditing, virus scanning, measuring storage and the ransomware guard all work at user level. Only three things need administrator rights: deleting Windows' own junk (the system temp folder, the update store, the old Windows install), stopping or disabling a service, and counting network bytes per process. The download ships with Chay bang quyen quan tri.bat, and the app itself has a Relaunch as administrator button on the Settings and Cleaner screens.

Running it in three steps

  1. 1

    Download BKSafe-1.3.0-win-x64-portable.zip and unzip it into a folder.

  2. 2

    Double-click bksafe.exe. There is no installation step.

  3. 3

    To clear the system's own junk, use the bundled Chay bang quyen quan tri.bat.

Copy the whole folder anywhere and it runs — a USB stick, a network share, another PC; just keep the folder's contents together. Your settings live in %APPDATA%\BKSafe\BKSafe, so deleting the app folder does not lose them. The app has no code-signing certificate yet, so the first launch may bring up a blue SmartScreen panel — click More info then Run anyway.

Linux build

Your Linux machine, fully measured.

The same BKSafe, built for Linux: junk cleanup, storage and memory insight, virus scanning, real-time protection for newly arrived files, service auditing, drive health, temperature and network activity. Installs as a standard .deb and removes cleanly.

  • Version 1.3.1 · build 24
  • Debian 12 / Ubuntu 22.04 or newer
  • .deb — installs and removes cleanly

Installing it in three steps

  1. 1

    Download BKSafe-1.3.1-linux-amd64.deb.

  2. 2

    Double-click it to open your software installer, or run sudo apt install ./BKSafe-1.3.1-linux-amd64.deb in a terminal.

  3. 3

    Open BKSafe from the applications menu, or type bksafe in a terminal.

The package installs any dependencies your machine is missing, adds an entry to the applications menu, and removes cleanly with sudo apt remove bksafe. Your settings live under ~/.config and ~/.local/share/bksafe, so removing the package does not lose them. A few readings depend on optional system utilities; where those are not present, the app reports the reading as unavailable rather than estimating a number.

Questions that come up.

Does BKSafe send my data anywhere?

No. Scanning and measurement run entirely on the device. The app does not upload your files, your process list or your machine figures to any server — and you can check that yourself on the app's own Network screen, which lists traffic per process.

Why is the macOS build not on the Mac App Store?

Apps on the Mac App Store must run sandboxed, and the sandbox blocks access to the hardware, storage and system information BKSafe reports on. BKSafe is therefore distributed with a Developer ID and Apple notarization.

Will macOS block it when I open it?

No. The macOS build is signed with a Developer ID and notarized by Apple, with the ticket stapled to both the DMG and the app inside. Drag it into Applications and open it like anything else, even with no network connection.

Does it work on Intel Macs?

Yes. It is a universal binary that runs natively on both Intel (x86_64) and Apple Silicon (arm64). There is one file to download, and no build to choose between.

Does the Windows build need installing?

No. It is a portable package: unzip it into a folder and double-click bksafe.exe. Copy the whole folder to a USB stick or another PC and it still runs — just keep the folder's contents together. Your settings are kept separately in %APPDATA%\BKSafe\BKSafe.

Windows shows “Windows protected your PC” — what now?

Click More info then Run anyway. The app has no code-signing certificate yet, so SmartScreen warns on the first few launches. If it will not start at all, right-click bksafe.exe → Properties → tick Unblock at the bottom of the General tab → OK. You can compare the SHA-256 published in the Download section to confirm the file is intact.

When do I have to run it as administrator?

Only to delete Windows' own junk, to stop or disable a service, or to count network bytes per process. For those, use the bundled Chay bang quyen quan tri.bat, or press Relaunch as administrator inside the app. For everyday use, ordinary user rights are enough.

How do I know the download is genuine?

On a Mac run shasum -a 256 BKSafe-1.3.2.dmg; on Windows open PowerShell and run Get-FileHash BKSafe-1.3.0-win-x64-portable.zip -Algorithm SHA256; on Linux run sha256sum BKSafe-1.3.1-linux-amd64.deb. Compare the result with the SHA-256 published in the Download section — matching strings mean the file is intact.

Do the builds share an account?

No. The macOS, Windows and Android apps are independent, each working on its own device. There is no shared account and nothing syncs between them.

How does Lite differ from the full BKSafe?

BKSafe Lite (com.tdson.bksafelite) covers file scanning, junk cleanup, a battery check and a network speed test. It runs no background service, so it stays light on an older phone. Scam call blocking, background service inspection, the vault and the safety score are in the full BKSafe build. They are separate apps, so you can keep both installed.
