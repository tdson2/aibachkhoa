macOS build

Your Mac, measured down to the core.

BKSafe reads straight from the kernel and the machine's own sensors, refreshed every two seconds. No decorative charts — every figure is something actually happening inside the Mac.

  • Version 1.3.0 · build 23
  • macOS 11 Big Sur or later
  • Universal · Intel & Apple Silicon

System

CPU, GPU, memory, storage and network side by side. Machine spec, uptime, process count and memory pressure on one screen.

CPU, core by core

Load on each core with performance and efficiency clusters kept apart, 1/5/15-minute load averages, and the processes eating the most CPU.

GPU

Utilisation, renderer and tiler activity, graphics memory in use against its limit, core count, and how often the driver had to rebuild the GPU.

Memory

Split the way macOS actually splits it: app memory, wired, compressed and file cache — with memory pressure and how much has been swapped out.

Disk health

Reads the drive's own SMART log: wear level, spare blocks left, total written, unsafe shutdowns, media errors and drive temperature.

Temperature

Every thermal sensor in the machine, which one is hottest right now, and whether the Mac is throttling because of heat.

Network

Who is moving data, how much of it, over which interface, and which ports this Mac exposes — broken down per process.

Anomaly alerts

Samples every two seconds and speaks up only when a figure stays outside its range across several samples. You set the thresholds, so opening a heavy app is not an anomaly.

Cleaner

Finds caches, logs, temporary files and leftovers from apps you removed. You see the list, then you decide what goes.

Malware scan

Sweeps the folders that get targeted and everything that launches with the Mac, matched against known macOS adware and malware signatures.

Security audit

Checks macOS's defence layers, open ports and everything that starts itself with the Mac. Reads settings only — changes nothing.

Settings

Set alert thresholds, choose whether notifications appear, and decide how much the app does in the background.

Why the app asks for Full Disk Access

BKSafe reads IORegistry to pull the drive's SMART figures and thermal sensor data, calls macOS system tools such as diskutil, nettop, lsof and tmutil, and walks junk folders that sit outside the app's own container. That is why it runs outside the sandbox and ships through a Developer ID rather than the Mac App Store — the same route CleanMyMac, iStat Menus and Little Snitch take. The access is used for reading only; nothing is sent anywhere.

No right-click-then-Open, no trip to Settings to unblock it, no “unidentified developer” warning. Apple's notarization ticket is stapled to both the DMG and the app inside it, so the Mac opens it fine even with no network connection.

Windows build

Your PC, with nothing left in the dark.

The same BKSafe, written for Windows: ten screens reading real figures from the operating system — cleaner, storage, virus scanning by file content, ransomware guard, background services, and an alert when something goes out of range. No installer: unzip it, double-click it, it runs.

  • Version 1.3.0 · build 23
  • Windows 10 64-bit or later
  • Portable — no installation

Cleaner

Finds what Windows and your apps leave behind: temp folders, the update store, browser caches, the old Windows install. It only lists — nothing is deleted until you pick it.

Storage

Which folders and which files are taking up the room — measured, not estimated. View by folder, by largest file, or by file type.

Memory

Where the RAM is going and which process is holding it, plus the file cache that can be handed back when the machine needs it.

Virus scan

Reads the contents of each file and matches it against signatures — no guessing from names or extensions. You choose the folders to sweep.

Ransomware guard

Watches behaviour rather than samples: the moment a batch of documents is overwritten and renamed within seconds, the app speaks up.

System safety

Whether Windows' defence layers are switched on, what starts itself with the machine, and whether any patch is waiting.

System services

What is running in the background with system rights, who signed it and where it lives — a newly installed service shows up within a second or two.

Network

How much is moving, which process is moving it, and which ports are open to the outside.

Drive

Hardware health, read and write throughput, and how fragmented each volume is.

Monitor

The whole machine on one screen, with every alert it has raised. It speaks up only when a figure sits outside the range you set.

Scan history

Every sweep is recorded: when it ran, over what, what it found and on what evidence. Cancelled runs go in the log too — a log holding only successful runs cannot answer "did I scan yesterday".

Scheduled scans

Set it to daily, weekly or monthly and leave it. The settings card states exactly when the next run falls, so you are not left guessing and scanning again just in case.

Start with the system

The background watchers only work while the app is open. Turn this on and they run from the moment you sign in. The entry is written under your own account — no administrator rights needed.

Collapse to a widget

Shrink the whole app into a small panel floating on the desktop: a few live figures, and a strip that lights up when something needs your decision.

When you need administrator rights

For everyday use the normal build is enough — auditing, virus scanning, measuring storage and the ransomware guard all work at user level. Only three things need administrator rights: deleting Windows' own junk (the system temp folder, the update store, the old Windows install), stopping or disabling a service, and counting network bytes per process. The download ships with Chay bang quyen quan tri.bat, and the app itself has a Relaunch as administrator button on the Settings and Cleaner screens.

Running it in three steps

  1. 1

    Download BKSafe-1.3.0-win-x64-portable.zip and unzip it into a folder.

  2. 2

    Double-click bksafe.exe. There is no installation step.

  3. 3

    To clear the system's own junk, use the bundled Chay bang quyen quan tri.bat.

Copy the whole folder anywhere and it runs — a USB stick, a network share, another PC; just do not separate bksafe.exe from the data folder and the .dll files beside it. Your settings live in %APPDATA%\BKSafe\BKSafe, so deleting the app folder does not lose them. The app has no code-signing certificate yet, so the first launch may bring up a blue SmartScreen panel — click More info then Run anyway.

Linux build

Your machine, measured from the kernel itself.

The same BKSafe, written for Linux: thirteen screens reading straight from /proc, /sys and systemd — cleaner, storage, memory, virus scanning by file content, a guard that checks new files the moment they land, a systemd service audit that cross-checks every binary against your package manager, plus drive health, temperature and network. Installs as a normal .deb and removes cleanly.

  • Version 1.3.0 · build 23
  • Debian 12 / Ubuntu 22.04 or newer
  • .deb — installs and removes cleanly

Installing it in three steps

  1. 1

    Download BKSafe-1.3.0-linux-amd64.deb.

  2. 2

    Double-click it to open your software installer, or run sudo apt install ./BKSafe-1.3.0-linux-amd64.deb in a terminal.

  3. 3

    Open BKSafe from the applications menu, or type bksafe in a terminal.

The package pulls in whatever GTK libraries your machine is missing, puts an icon in the applications menu, and removes cleanly with sudo apt remove bksafe. Your settings live under ~/.config and ~/.local/share/bksafe, so removing the package does not lose them. A few readings need optional tools that most desktops already have — smartmontools for drive health, e2fsprogs for fragmentation, policykit-1 for anything needing administrator rights; without them the app says the reading is unavailable rather than inventing a number.

Questions that come up.

Does BKSafe send my data anywhere?

No. Scanning and measurement run entirely on the device. The app does not upload your files, your process list or your machine figures to any server — and you can check that yourself on the app's own Network screen, which lists traffic per process.

Why is the macOS build not on the Mac App Store?

App Store apps must run sandboxed, and inside the sandbox you cannot read the drive's SMART figures, cannot read thermal sensors and cannot walk junk folders outside your own container. So BKSafe ships through a Developer ID with Apple notarization — the route CleanMyMac, iStat Menus and Little Snitch take.

Will macOS block it when I open it?

No. Build 1.3.0 is signed with a Developer ID and notarized by Apple, with the ticket stapled to both the DMG and the app inside. Drag it into Applications and open it like anything else, even with no network connection.

Does it work on Intel Macs?

Yes. It is a universal binary that runs natively on both Intel (x86_64) and Apple Silicon (arm64). There is one file to download, and no build to choose between.

Does the Windows build need installing?

No. It is a portable package: unzip it into a folder and double-click bksafe.exe. Copy the whole folder to a USB stick or another PC and it still runs — just do not separate bksafe.exe from the data folder and the .dll files beside it. Your settings are kept separately in %APPDATA%\BKSafe\BKSafe.

Windows shows “Windows protected your PC” — what now?

Click More info then Run anyway. The app has no code-signing certificate yet, so SmartScreen warns on the first few launches. If it will not start at all, right-click bksafe.exe → Properties → tick Unblock at the bottom of the General tab → OK. You can compare the SHA-256 published in the Download section to confirm the file is intact.

When do I have to run it as administrator?

Only to delete Windows' own junk, to stop or disable a service, or to count network bytes per process. For those, use the bundled Chay bang quyen quan tri.bat, or press Relaunch as administrator inside the app. For everyday use, ordinary user rights are enough.

How do I know the download is genuine?

On a Mac run shasum -a 256 BKSafe-1.3.0.dmg; on Windows open PowerShell and run Get-FileHash BKSafe-1.3.0-win-x64-portable.zip -Algorithm SHA256; on Linux run sha256sum BKSafe-1.3.0-linux-amd64.deb. Compare the result with the SHA-256 published in the Download section — matching strings mean the file is intact.

Do the builds share an account?

No. The macOS, Windows and Android apps are independent, each working on its own device. There is no shared account and nothing syncs between them.

How does Lite differ from the full BKSafe?

Lite (com.tdson.bksafelite) keeps four things: file scan, junk cleanup, battery check and a network speed test. It matches TLSH signatures instead of running an AI model, and it runs no background service — so it is lighter and easier on the battery of an older phone. Scam call blocking, the background-service scan, the vault and the safety score are in the full build only. They are separate apps, so you can keep both installed.
