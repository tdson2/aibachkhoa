BKSafe — 适用于 Windows、macOS、Linux 和 Android

概要

BKSafe 是由越南 AIBachKhoa（Son Tran）发布的一套防护与维护工具，共有四个版本：Windows、macOS、Linux 和 Android。

桌面版没有账户、没有遥测，也不会把任何结果发送到任何地方。每一次扫描、每一个数据和每一条日志都留在那台电脑上。Android 版会收集部分运行数据，下文完整列出。

桌面版（Windows、macOS、Linux）

这三个版本会读取大量关于你电脑的信息——这正是它们的工作。但这些信息都不会离开电脑。具体而言，应用会读取：

  • 硬件数据：CPU、内存、温度、硬盘健康状况、网络流量
  • 你选择扫描的文件夹中的文件内容，用于检查恶意软件
  • 进程、服务、驱动程序和启动项列表
  • 操作系统的安全配置：防火墙、反恶意软件、磁盘加密
  • 使用存储空间统计功能时的文件夹名称和大小

没有需要登录的账户，不生成任何设备标识符，也没有内置任何分析或崩溃报告。文件内容在本机检查后即被丢弃——不会被复制、不会被上传，也不会被保留。

应用确实写入磁盘的内容存放在你自己账户的配置文件夹中：语言选择、浅色/深色模式、警报阈值，以及你运行过的扫描记录。卸载应用并删除其设置即可全部清除。

桌面版何时连接网络

只有两种连接，且都不携带你的数据：

连接 时机与用途
恶意软件特征库更新 在应用启动时自动运行，使扫描器的恶意软件特征库保持最新。仅下载；除普通的文件请求外，不上传任何内容。
Windows Update 仅在你点击“更新”选项卡上的“立即检查”时进行。应用会询问操作系统自带的 Windows 更新服务是否有待安装的补丁；该连接发生在你的电脑与 Microsoft 之间。

除这两种之外，桌面版不会建立任何其他网络连接。你可以用任何网络监控工具验证这一点——包括本应用自带的“网络”页面。

Android 版收集哪些数据

为运行服务和检测威胁，Android 版会收集部分数据：

  • 电子邮件地址和使用数据
  • 设备信息：型号、系统版本、硬件标识符、IMEI、Android ID
  • 应用的使用频率和时长，以及执行了哪些操作
  • 崩溃日志和性能指标
  • 被扫描应用的包名，用于威胁检测

我们不收集你的个人文件——照片、视频、联系人、消息——除非你为某项特定功能明确授予访问权限。

Android 版申请的权限及原因

权限 用途
MANAGE_EXTERNAL_STORAGE 扫描存储文件夹中的恶意软件。
PACKAGE_USAGE_STATS 发现在后台行为异常的应用。
READ_CALL_LOG 将来电号码与诈骗号码列表进行比对。
VPNService 在设备本身上监控网络流量。这是本地的设备内连接——不会有任何流量经过我们的服务器。

数据用途

Android 版收集的数据仅用于以下目的：

  • 检测安全威胁
  • 改进和维护应用的运行
  • 管理你的账户
  • 履行法律义务
  • 在必要时与你联系

数据共享

我们承诺不出售用户数据，也不与第三方共享用户数据。例外情况有三种，我们在此明确列出，而不是藏在角落里：

  • 我们委托来运营服务的服务提供商（例如分析服务），且仅限其工作所需的最低限度
  • 法律要求时的有关当局
  • 未来发生合并或业务转让时的收购方

桌面版不涉及以上任何一种情况：你的数据不会离开电脑，因此无可共享。

存储与保留

所有与应用运行相关的数据都在你自己的设备上处理和存储。

卸载应用或使用应用内置的删除功能即可删除这些数据。在桌面版上，删除应用的配置文件夹即可清除它写入过的所有内容。

儿童隐私

本服务不面向 13 岁以下的用户。凡法律要求须征得父母或监护人同意的，我们遵守该要求。如果你认为你的孩子向我们提供了信息，请通过本页底部的地址联系我们，我们会将其删除。

你的权利

你有权访问、更正和删除你的数据，并有权反对我们处理这些数据。请将请求发送至本页底部的电子邮件地址。

在桌面版上，其中大部分权利你无需求助任何人即可自行行使：唯一存在的数据只是你自己文件夹中的少量设置和日志文件。

安全

由于桌面版将一切都保存在电脑本身，你的数据受操作系统自身防护的保护——即你的用户账户及其文件权限。对于 Android 版确实发送给我们的数据，我们在传输中使用加密连接，并将访问权限控制在最低必要范围。没有任何系统是绝对安全的，我们也不作此声称。

政策变更

本政策可能随应用变化而更新。顶部的“最后更新”日期始终反映当前生效的版本。对于会实质性影响你数据处理方式的变更，我们会在应用内告知，而不是悄悄修改本页。
