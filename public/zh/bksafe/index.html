为什么应用需要“完全磁盘访问权限”

BKSafe 报告的硬件、存储、网络和安全设置位于应用自身容器之外，还要清理散落在系统各处的垃圾文件。这需要“完全磁盘访问权限”，这也是 BKSafe 采用 Developer ID 签名和 Apple 公证发布、而不通过 Mac App Store 发布的原因。该权限仅用于读取，不会向任何地方发送任何内容。

常见问题。

BKSafe 会把我的数据发送到别处吗？

不会。扫描和测量完全在设备上运行。应用不会把你的文件、进程列表或机器数据上传到任何服务器——你可以在应用自带的“网络”页面亲自核实，那里按进程列出了所有流量。

为什么 macOS 版不在 Mac App Store 上架？

Mac App Store 上的应用必须在沙盒中运行，而沙盒会阻止访问 BKSafe 所报告的硬件、存储和系统信息。因此 BKSafe 采用 Developer ID 签名和 Apple 公证发布。

打开时 macOS 会阻止它吗？

不会。macOS 版已签名并经过 Apple 公证。拖入“应用程序”，像其他应用一样打开即可，即使没有网络连接也可以。

能在 Intel Mac 上运行吗？

能。同一个下载包可在 Intel 和 Apple Silicon Mac 上原生运行——无需在不同版本之间选择。

Windows 版需要安装吗？

不需要。它是便携包：解压到一个文件夹，双击 bksafe.exe 即可。把整个文件夹复制到 U 盘或另一台电脑上照样能运行——只要保持文件夹内容完整。你的设置与应用文件夹分开保存。

Windows 提示“Windows 已保护你的电脑”——怎么办？

点击更多信息，然后点击仍要运行。应用目前还没有代码签名证书，因此前几次启动时 SmartScreen 会发出警告。如果完全无法启动，请右键点击 bksafe.exe → 属性 → 在“常规”选项卡底部勾选解除锁定 → 确定。你可以对照“下载”部分公布的 SHA-256 来确认文件完好。

什么时候必须以管理员身份运行？

仅在少数系统级操作时需要：清理 Windows 自身的垃圾、停止或禁用某项服务，以及部分网络数据。遇到这些情况，请在应用内点击以管理员身份重新启动。日常使用时，普通用户权限就够了。

如何确认下载的文件是正版？

在 Mac 上运行 shasum -a 256 BKSafe-1.3.3.dmg；在 Windows 上打开 PowerShell 并运行 Get-FileHash BKSafe-1.3.0-win-x64-portable.zip -Algorithm SHA256；在 Linux 上运行 sha256sum BKSafe-1.3.1-linux-amd64.deb。将结果与“下载”部分公布的 SHA-256 进行比较——字符串一致即表示文件完好。

各版本共用一个账户吗？

不。macOS、Windows 和 Android 应用彼此独立，各自在自己的设备上工作。没有共享账户，它们之间也不会同步任何内容。

Lite 版与完整版 BKSafe 有什么区别？

BKSafe Lite（com.tdson.bksafelite）提供文件扫描、垃圾清理、电池检查和网速测试。它不运行后台服务，因此在旧手机上也很轻盈。诈骗电话拦截、后台服务检查、保险箱和安全评分在完整版 BKSafe 中提供。两者是独立的应用，可以同时安装。
