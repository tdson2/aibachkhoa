Android 应用 · 浏览器版 · J2ME

你第一部手机上的游戏，又能玩了。

JeMul 是一款 Java ME 模拟器。安装 Android 应用，导入你自己的 .jar 文件即可开玩；或者打开浏览器版，上千款游戏早已就位——无需安装，无需配置。

这是什么

它是模拟器，不是下载站。

JeMul 可运行 MIDP 应用——也就是大约 2001 年至 2012 年间功能机上运行的 .jar 文件。它本身不附带任何游戏内容：在 Android 上需要你自备文件，浏览器版则带有运营方预先配置好的游戏库。

真实按键

完整的手机键盘：方向键、左右软键、0–9、星号和井号键、清除键。在电脑上，每个按键都对应一个可自定义的键盘按键；在手机上，它们就是你拇指下的按钮。

为老屏幕而生

这些游戏的画面尺寸从 128×128 到 480×800 不等。JeMul 在缩放时保持像素清晰、维持原始宽高比，还能为需要横屏手机的版本旋转画面。

进度不会丢

最高分和游戏存档按原游戏期望的方式保存，并在多次游玩之间保留。今天退出，明天回来也能从上次的地方继续。

Android 应用

把 JeMul 装进手机。

添加一个 .jar 或 .jad 文件，它就会连同图标和大小出现在你的游戏库中。一切都在设备上运行——无需账号，无需服务器，文件放进手机后也不再需要网络。

  • 直接从存储中导入 .jar 和 .jad 文件
  • 游戏库支持搜索、最近游玩和单个游戏详情
  • 屏幕键盘提供 Nokia、Samsung 和 Sony Ericsson 布局
  • 全屏、锁定宽高比、尺寸和帧率设置
  • 游戏音效，每次按键都有触感反馈

浏览器版

无需安装。

浏览器版打开即用，游戏运行流畅，而不是 2006 年手机的那种速度。用 Google 登录，然后开始游戏。

  • 上千款游戏的游戏库，可搜索、可筛选
  • 每秒 60 帧，游玩时显示实时帧率
  • 支持键盘、用鼠标操作触屏游戏，以及屏幕键盘
  • 可自由调整的玻璃风格界面：颜色、模糊、缩放、扫描线
  • 手机上同样好用：按键和画面同屏显示，无需滚动
