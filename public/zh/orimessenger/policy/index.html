隐私政策

OriMessenger —— 适用于 Windows、macOS、Linux、Android 和 iOS。

最后更新：2026 年 9 月 26 日

简要说明。OriMessenger 没有账号，也不需要手机号。每条消息正文、头像和附件都在两台设备之间进行端到端加密。当应用需要连接互联网时，我们的中继服务器会传送它无法打开的加密消息 —— 但它确实能看到谁在什么时候发给了谁，因为它必须为消息选择路由。有两件事是刻意不保密的：您设定的显示名称和状态文字可被附近任何运行 OriMessenger 的设备读取；中继服务器会将投递元数据保留最多 30 天。下文对两者均有说明。

设备上存储了什么

首次启动时，应用会在设备上创建您的身份：一组加密密钥（用于保护您的消息，并向联系人证明消息确实来自您），以及您的 16 位用户 ID。其中的私密部分永远不会离开您的设备。以下所有内容都保存在应用自己的私有数据文件夹中：

平台存储位置
Windows您的 Windows 用户配置文件中的应用数据文件夹。
macOS您的 macOS 用户账户中的应用数据文件夹。
Linux您的主目录中的应用数据文件夹。
Android应用的私有存储空间。它被排除在 Android 云备份之外，因此不会被复制到 Google Drive。
iOS应用的私有存储空间 —— 聊天记录和密钥绝不会通过“文件”应用或 iTunes 文件共享暴露。
  • 您的身份密钥。其中的私密部分永远不会离开设备。
  • 您设定的显示名称、状态文字、头像颜色和背景。
  • 您的好友列表、屏蔽列表以及所有待处理的好友请求。
  • 聊天记录以及您发送或接收的附件。
  • 您每个会话的加密密钥。
  • 应用偏好设置：语言、浅色/深色模式、默认发送渠道。

卸载应用或清除其数据会删除以上所有内容。不存在由我们控制的云端备份。

请清楚了解静态数据的保护方式。您的聊天记录和私钥以未加密形式存储在应用的数据文件夹中。应用不会在此之上额外添加密码或第二层加密。它们由您的操作系统保护：在 Android 和 iOS 上是应用沙盒，在桌面系统上是您的用户账户和全盘加密（FileVault、BitLocker、LUKS）。任何能在已解锁设备上以您的用户身份读取文件的人，都能读取您的聊天记录。如果您在意这一点，请启用全盘加密并设置设备密码。

消息可能经过的三种网络路径

OriMessenger 按以下顺序尝试各条路径，并在第一条可用的路径处停止：

路径传输的内容及去向
Bluetooth 设备通过 Bluetooth 使自己可被发现，并搜索附近的其他 OriMessenger 设备。消息在设备之间直接传递 —— 不经过基站、不经过路由器，任何内容都不会离开您身边的范围。请注意，设备还会发布一份简短的公开资料，以便他人发现它：参见附近的设备能看到什么。
Wi-Fi / LAN 同一本地网络中的设备会相互广播自己的存在，然后直接连接。流量始终留在本地网络内，即使互联网被屏蔽也能工作。这些广播对网络上的每一台设备都可见：参见附近的设备能看到什么。
互联网中继 仅在上述两种路径都失败时使用。设备与 AIBachKhoa 运营的中继服务器建立加密连接，并交出以收件人 ID 为地址的加密消息。中继服务器能看到什么一节准确说明了它会保留哪些内容。

附近的设备能看到什么

这是 OriMessenger 中唯一不经过端到端加密的部分，在选择显示名称之前值得先了解清楚。

为了让人们无需账号或服务器即可找到彼此，每台设备都会发布一份简短的公开资料，其中包含您的用户 ID、显示名称、状态文字、头像颜色以及您的公钥。它绝不包含您的私钥、聊天记录或好友列表。

范围内任何正在搜索的人都能读取这份资料 —— 不仅限于您的联系人：

  • 通过 Bluetooth 时，这份资料以任何范围内设备都可读取的方式发布。没有配对步骤，也没有确认提示，因为陌生人首先必须能读取您的名字，才能向您发送好友请求。
  • 通过 Wi-Fi 时，同一份资料会包含在发送给本地网络上每台设备的广播中。

这份资料使用您的身份签名，因此网络上的任何人都无法把您的名字冒用在他们的地址上。但它并不保密。实际而言：

  • 在同一家咖啡馆、办公室或教室里运行 OriMessenger 的任何人，都能看到您设定的显示名称和状态文字，并能得知您的设备在场。
  • 如果您不希望被看到，请在设置中关闭附近。这会让您无法再通过 Bluetooth 和 Wi-Fi 被发现；互联网中继仍会继续工作，因此现有会话依然可以收发消息。
  • 如果您预计会身处公共场所，请使用昵称而非真实姓名。您的用户 ID 本身不会透露任何信息，但您输入的名字会按原样显示。

消息内容绝不在其中。一旦两台设备决定通信，资料交换之后的一切内容都经过端到端加密。

中继服务器能看到什么

互联网中继会暂存消息，直到可以投递为止。每台设备都通过加密连接接入中继，并证明自己拥有对应的 ID。当您的设备有消息要发给某个已知 ID 的人时，中继会存储一条记录，其中包含：

  • 收件人的用户 ID（16 位字符）。
  • 发件人的用户 ID —— 也就是您的 ID。中继需要它来执行屏蔽列表，并让收件人的设备验证签名。
  • 一个时间戳，用于让记录过期。
  • 加密消息，只有您的设备和收件人的设备才能打开。其中包括所有附件数据，以及您的名字、头像或状态等任何人类可读的元数据。
  • 任何互联网连接都会携带的网络信息：您的 IP 地址和一个临时连接 ID。

因此，中继确实会获知投递元数据：谁在什么时候给谁发了消息，以及消息的大致大小。只要还要向离线设备投递消息，我们就无法通过设计消除这一点。如果您在意这些元数据，请通过 Bluetooth 或 Wi-Fi 使用 OriMessenger，这两种方式完全不涉及服务器。

中继还会保存一份屏蔽列表：当您屏蔽某人时，（您的 ID，对方的 ID）这一对会存储在服务器端，以便中继在对方的消息到达您的设备之前就予以拒绝。此列表没有过期时间；在您解除屏蔽该人时或应您的要求，它才会被删除。

中继看不到：

  • 消息文字或媒体内容。它没有解密所需的密钥。
  • 您的显示名称、头像或状态 —— 这些都在加密消息内部传输。
  • 您的好友列表、待处理的请求，或您通过 Bluetooth 或 Wi-Fi 交换的任何内容。这些路径从不经过服务器。
  • 任何手机号、电子邮件地址或第三方账号。您的 ID 不与任何此类信息关联。

存储的消息会在收件人设备确认收到时立即删除，或在 30 天后删除，以先到者为准。

网络和 Wi-Fi 状态（Android）用于检测 Wi-Fi 是否开启，以及设备所在的局域网是否值得尝试。
后台运行和开机自启（Android）用于在应用处于后台时继续发现附近用户并投递消息，并在重启后恢复运行。可选 —— 您可以在设置中关闭此功能。

与第三方共享

我们不出售用户数据，也不与广告网络共享用户数据。与您相关的任何信息离开我们系统的情形仅限于：

  • 托管中继的基础设施提供商（一家越南云服务提供商）—— 它们能看到经过中继的加密消息，所见不会多于中继本身。
  • 执法机关，在我们依法必须回应有效请求时。鉴于中继只保存加密消息和投递元数据，可提供的有用信息很有限；如被问及，我们会如实说明。
  • 发生合并或收购时的承继实体。任何转让都将沿用本政策。

保留与删除

聊天记录、密钥材料和个人资料设置会一直保存在您的设备上，直到您将其删除。在所有平台上，卸载应用都会将其清除。

中继上未投递的消息会在收件人取回后或 30 天后被丢弃。已投递的消息会立即被丢弃。

服务器端的屏蔽条目（您的 ID 与您屏蔽的 ID 配对）没有过期时间。当您在应用中解除屏蔽该人，或您要求我们按 ID 清除您的中继数据时，这些条目才会被删除。

中继流量的服务器端日志（连接元数据、时间戳、字节数 —— 不含消息内容，也不含用户 ID）最多保留 14 天，用于运维排错，之后轮换删除。

儿童隐私

OriMessenger 不面向 13 岁以下的用户。在要求家长同意的司法管辖区，我们遵守当地规定。如果您认为有儿童创建了 ID 并希望将其删除，请附上该 ID 写信至下方地址；我们可以删除中继上的相应数据。

您的权利

由于没有账号，您通常需要向公司行使的大多数权利，都可以直接在设备上自行行使：访问、更正、删除和导出，都只需打开应用即可。在应用内，您可以清除全部聊天记录、移除联系人、关闭附近以停止被发现，还可以屏蔽或举报任何向您发送骚扰内容的人。举报会在您的设备上生成，并发送至下方地址 —— 我们会对举报采取行动，并可按 ID 删除中继数据。

如果您需要我们协助处理某些事项 —— 例如删除您在中继上的数据、清除服务器端的屏蔽条目 —— 请附上相关 ID 写信至下方地址。

安全

所有发往中继的互联网流量在传输过程中均经过加密。此外，每条消息都在两台设备之间进行端到端加密并签名，因此收件人既能验证内容未被篡改，也能验证消息确实来自您。中继只负责传送结果，不持有任何能够打开它的密钥。

设备上的数据不会由应用另行加密。正如设备上存储了什么中所述，聊天记录和私钥由操作系统保护，而非由应用密码保护。我们宁愿直截了当地说明这一点，也不愿暗示应用提供了它并不具备的保护。

Android APK 和 Google Play 版本使用的签名证书指纹为：

SHA-256   8A:0D:79:F8:73:F4:8F:A6:F3:E5:BD:5A:C5:04:28:A5:21:C1:86:C4:B1:0A:46:20:EE:D3:89:BA:48:F4:33:32

Windows 安装程序目前尚未进行代码签名；请改为对照下载页面上公布的 SHA-256 进行校验。

没有任何系统是绝对安全的，我们也不作此承诺。如果您发现漏洞，请将详细信息发送邮件至 contact@aibachkhoa.com，而不要公开发布。

本政策的变更

本政策可能随应用的变化而变更。页面顶部的“最后更新”日期始终反映当前版本。对您的数据处理方式有实质影响的变更，将在应用内提示，而不仅仅是发布在本页面上。
